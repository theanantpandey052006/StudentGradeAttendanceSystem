# Project Statement

## Project Title

Student Grade & Attendance Management System

## Problem Statement

Managing student academic records manually can be time-consuming
and may lead to errors in marks, attendance and performance
calculations.

This project provides a simple Java-based system to manage student
information, academic marks, attendance and performance reports.

## Objectives

- To manage student information efficiently.
- To record and calculate academic marks.
- To automatically calculate percentage and grade.
- To record and calculate student attendance.
- To check attendance eligibility.
- To generate a consolidated student performance report.
- To apply Object-Oriented Programming concepts in Java.
- To implement input validation and error handling.

## Scope

The system provides basic student management, marks management,
attendance management, grade calculation, eligibility checking and
report generation.

The current version is a console-based Java application using
in-memory collections and simple file handling.

## Target Users

- Students
- Faculty members
- Academic departments
- Educational institutions

## Major Functional Modules

1. Student Management
2. Marks Management
3. Attendance Management
4. Grade Calculation
5. Attendance Eligibility
6. Report Generation
7. Data Saving
8. Input Validation

## Technologies Used

- Object-Oriented Programming
- Java Collections
